# Manjil Shilakar — Portfolio Website

A responsive, static portfolio site built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser, or run a local server:
```bash
python3 -m http.server 8000
```
Then visit http://localhost:8000.

## Deploy free
1. Create/sign in to a GitHub account and create a public repository.
2. Upload the contents of this folder.
3. Import the repository into a static hosting provider such as Cloudflare Pages, GitHub Pages, Netlify or Vercel.
4. Choose the free plan and publish. The provider will assign a free subdomain (for example, `project.pages.dev` or `project.vercel.app`).

## Before publishing
The public LinkedIn preview supplied enough information to populate the current role, location, education institution/year and six visible credentials. LinkedIn restricted access to the full profile, so earlier roles, full work history, detailed project outcomes, skills, contact email and a CV were not guessed. Update these from your LinkedIn profile before presenting the site as a complete factual CV.
